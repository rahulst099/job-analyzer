# Job Analyzer - ATS Score Checker 🚀

Apni Job Description aur Resume ko compare karke ATS Score nikalta hai.

## Features
- Real-time ATS Score Calculation
- Matched & Missing Skills Detection
- AI Suggestion for Resume Improvement
- History Saved in MongoDB
- PDF Resume Upload

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Deployment: Vercel + Render
