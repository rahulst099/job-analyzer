# Job Analyzer - ATS Score Checker

Resume upload karo, ATS Score pao, aur apni Dream Job ke liye ready ho jao.

## Features
- Resume Upload (PDF)
- ATS Score Check
- Skills Match
- Job Description Match

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
